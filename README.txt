MOSTAFA SAMY — PORTFOLIO WEBSITE

FINAL STATIC WEBSITE PACKAGE

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Keep index.html, styles.css, script.js, the assets folder and the projects folder together.

HOW TO PUBLISH
Upload the extracted website folder contents to your static hosting provider (for example, Netlify Drop). The index.html file must be at the published site root. This is a static HTML/CSS/JavaScript website; no database or CMS setup is required for this version.
